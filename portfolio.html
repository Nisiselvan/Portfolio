PROJECTS

Object Location System for Visually Impaired
ATmega328P · RFID RC522 · SPI/UART

A hardware aid that helps a visually impaired user identify nearby objects. Each object carries a small RFID tag; when the RC522 reader picks up a tag, the ATmega328P microcontroller identifies it and triggers a GPIO buzzer with a distinct pattern so the user knows what's nearby without needing to see it.

The RFID reader talks to the microcontroller over SPI, while UART was used to log data for debugging. During testing, the SPI/UART communication was unreliable — I used a logic analyzer to capture the signal timing, traced the fault to a wiring/protocol mismatch, and fixed it so tag reads registered consistently. Firmware was kept to basic Embedded C, since the focus of the project was the hardware and sensor integration rather than the software.

FPGA Cricket Score Display System
Verilog HDL · FPGA · Xilinx ISE · 7-Segment Display

A live cricket score counter built entirely in digital logic. I wrote the score-counter circuit in Verilog HDL — counters and control logic that increment runs and track state on button input — then simulated and synthesized the design in Xilinx ISE.

The synthesized design was deployed onto real FPGA hardware, with the running score driven out to a 7-segment display. This project was my first hands-on pass at taking an RTL design from simulation all the way through to working hardware.
